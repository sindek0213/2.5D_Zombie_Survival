# 2.5D Zombie Survival

Unity 2022.3.62f2와 URP로 만든 3D 월드 기반 2.5D 탑다운 프로토타입입니다.

## 코드 학습

전체 코드의 역할, 시스템 연결 관계와 초보자용 추천 학습 순서는 [`CODE_STUDY_GUIDE.md`](CODE_STUDY_GUIDE.md)에 정리되어 있습니다. 다른 채팅에서 코드를 천천히 설명받을 때 사용할 수 있는 복사용 시작 문장도 문서 마지막에 포함되어 있습니다.

## 현재 구현 범위

- `Bootstrap`, `Hideout`, 다섯 파밍 구역을 가진 36×36 `RaidPrototype` 씬
- Bootstrap에서 저장 데이터를 초기화하고 짧은 안내 후 Hideout으로 자동 진입
- 플레이어가 직접 걸어 다니며 E키로 창고·임무 보드·제작대·치료소·발전기를 사용하는 24×24 물리 거점
- 고철·전자 부품·천 조각을 소비하는 시설 강화, 레벨별 월드 외형 변화와 실제 기능 효과
- 창고 레벨별 보관 행 확장, 임무 보드 레벨별 공개 임무 증가, 발전기 레벨별 제작 비용 할인
- 제작대의 9mm·5.56mm·12게이지 탄약 제작과 치료소의 레벨별 구급상자 제작 수량 증가
- 좀비 처치·아이템 회수·성공 탈출 임무, 일회성/반복 가능 규칙과 임무별 완료 횟수 저장
- 임무 완료 시 실제 아이템 보상을 창고에 지급하고, 전체 보상 공간이 부족하면 아무것도 바꾸지 않는 안전 검사
- 남쪽 시작 캠프→서쪽 주거·보급 구역/동쪽 창고·무기 구역→중앙 검문소→북쪽 탈출 구역으로 이어지는 3D 파밍 맵
- 충돌 가능한 외곽 벽·건물 잔해·창고 선반·검문소 엄폐물과 이동을 막지 않는 구역별 바닥 색상
- `CharacterController` 기반 WASD 이동(대각선 속도 정규화)
- 인벤토리를 열어도 계속되는 레이드 포만감 감소와 포만감 20 미만에서 최대 75%까지 적용되는 이동 속도 페널티
- 좌우 Shift 달리기, 100 기력의 소모·회복과 완전 고갈 뒤 25까지 회복해야 다시 달릴 수 있는 탈진 규칙
- 마우스 위치를 지면에 투영하는 조준과 이동 중에도 커서 방향을 우선하는 8방향 캐릭터 주시
- 총기를 든 채 우클릭을 유지하면 FOV가 부드럽게 확대되고 명중 오차가 기본값의 35%로 감소하는 정밀 조준
- 카메라를 향하는 2D 플레이어 스프라이트와 3D 캡슐 충돌체
- 고정 각도 카메라 추적
- 마우스 좌클릭과 Raycast 기반 장착 무기 명중 판정
- 발사 위치부터 명중점까지 표시되는 짧은 탄도선과 총구 빛
- 외부 음원 없이 생성되는 임시 발사·피격·사망 효과음
- `WeaponDefinition` 기반 무기별 피해량, 사거리, 연사 속도, 재장전 시간, 탄창, 사용 탄종, 명중 오차와 적 밀림
- 반자동 10발 권총, 자동 20발 소총, 자동 30발 기관단총과 반자동 5발 산탄총
- 권총·기관단총은 9mm, 소총은 5.56mm, 산탄총은 12게이지만 사용하며 다른 탄종으로는 재장전할 수 없음
- 산탄총은 쉘 한 발을 소비해 7개 펠릿을 16도 범위로 발사하고 가까운 거리에서 최대 98 피해
- R키 재장전 시 인벤토리의 맞는 탄약 묶음을 실제로 소비하고, 부족하면 남은 양만큼만 장전
- 무기 인스턴스마다 탄창 수량을 따로 유지하고 레이드 결과와 거점 저장에도 남은 장탄 수 보존
- 테스트 레이드 시작 시 보조무기 슬롯에 실제 권총 장착, 무장 해제 상태에서는 발사 차단
- 테스트 지급 권총도 실패 시 제거하지만 무료 장비이므로 탈출 보상과 사망 손실 수량에서는 제외해 창고 복제 방지
- 공통 피해 인터페이스와 체력 기반 연습 표적
- 방탄복 장착 시 설정된 비율만큼 피해를 내구도로 흡수하고, 내구도 0에서 방어 효과 제거
- 방탄복 현재 내구도를 장비 슬롯·아이템 상세·체력 HUD에 표시하고 레이드 결과와 저장 파일에 보존
- 현재 구역, 무기, 탄약, 재장전, 체력·방탄 내구도, 포만감과 기력 상태를 표시하는 Canvas HUD
- 감지, 추적, 근접 공격, 사망 상태를 가진 기본 좀비 AI
- 실행 시 맵 Collider로 생성되는 NavMesh를 이용해 긴 벽·건물과 다른 좀비를 우회하고, 총기 명중 시 감속되는 밀림 적용
- 맵 가장자리 8개 지점에서 빈 생존 자리를 채우는 좀비 스폰 시스템
- 초록 일반형·노란 빠른형·붉은 튼튼한형 3종 좀비 데이터와 시간에 따른 최대 생존 수·생성 간격 난이도 상승
- 좀비 인스턴스별 전리품 목록과 확률·수량 설정, 사망 시 8×6 시체 격자 생성 및 직접 수색
- 생활 보급·무기·은닉물 3종 필드 상자와 종류별 가중치·수량 전리품 표
- 첫 수색 때만 상자 내용물을 생성하고 재수색 시 전리품이 복제되지 않는 지연 생성 방식
- 플레이어 체력 Canvas HUD
- 좀비 피격 색상 점멸과 Canvas 기반 플레이어 피격 화면 표시
- `ScriptableObject` 기반 탄종별 탄약, 의료품, 식량, 퀘스트·강화 재료 정의와 일반·고급·희귀·퀘스트 등급
- 아이템 한 개와 현재 묶음의 기본 가치를 상세 화면에 표시하는 경제 밸런스 기준값
- E키 상호작용 루팅과 10×6 타르코프식 격자 인벤토리
- 단일 바닥 아이템과 시체는 통과 가능한 Trigger를 사용하고, 필드 아이템 상자는 단단한 장애물 Collider 사용
- 모든 게임 화면을 `Canvas + Image + Text + Button` 프리팹으로 구성해 Inspector에서 디자인 수정 가능
- 교체 가능한 인벤토리 격자·아이템·장비 슬롯 프리팹
- 인벤토리를 열고 닫을 때 시간 정지와 무관하게 재생되는 짧은 확대·축소 및 페이드 효과
- 아이템 이름·수량·E키와 획득 성공 또는 공간 부족을 구분하는 상호작용 안내
- 아이템별 격자 크기, 중첩, 드래그 이동, R키 회전, 공간 검사
- 인벤토리를 연 동안 이동·조준·발사·재장전·루팅 조작 잠금
- 주무기, 보조무기, 방탄복, 전술 조끼, 가방 장비 슬롯
- 장착한 총기를 즉시 현재 발사 무기로 선택하고 HUD에 사용 중인 무기 표시
- 전술 조끼와 가방의 독립 내부 격자
- 중첩 분할, 1.5초 치료·1.2초 음식 사용, 진행률·실패 이유, 효과가 없을 때 소비 방지와 월드 아이템 버리기
- 퀘스트 무전기 보유 조건과 탈출 지점 활성화
- 제한 시간 없는 레이드와 좀비 3마리 처치·25초 생존 추가 탈출 조건
- 레이드 경과 시간·현재 처치 수·탈출 대기 시간을 표시하고 조건 미달 이유를 구체적으로 안내
- 탈출 구역 진입, 3초 카운트다운, 이탈 취소와 성공 상태
- 탈출 성공·플레이어 사망 감지와 중복 종료 방지
- 결과가 확정되면 플레이어 조작과 살아 있는 좀비 행동을 함께 멈추고, 다음 씬의 시간 배율을 정상값으로 복구
- 인벤토리·장비·컨테이너 내용을 저장 가능한 RaidResult 스냅샷으로 변환
- 사망 시 소지품, 장착 장비와 가방·조끼 내부 아이템을 즉시 전부 제거
- 결과 화면 표시 후 Hideout 씬 이동과 직전 결과 전달
- 탈출 성공 아이템을 Hideout 창고에 정확히 한 번 지급하고 사망 보상 차단
- 창고 12×10과 출격 준비 10×6 격자, 드래그 이동·교환·회전·빠른 이동·자동 정리
- 선택 아이템 상세 설명, 방어구 상태와 같은 슬롯 무기의 피해량·사거리·발사 간격·재장전 비교
- 출격 버튼으로 RaidPrototype에 진입하고 선택한 아이템을 플레이어 인벤토리에 복원
- 알 수 없는 아이템 ID나 공간 부족으로 복원하지 못한 출격품의 창고 반환
- 버전 5 JSON 파일로 격자 좌표, 컨테이너, 탄창, 방어구 내구도, 시설 레벨, 임무 진행도와 완료 기록을 게임 종료 후에도 보존
- 버전 1·2·3·4 저장 파일 호환, 평탄화된 부모 인덱스 구조와 손상 데이터 검증
- 보상 수령, 창고 이동, 출격 시작 시 자동 저장하고 손상된 저장 파일은 현재 메모리에 적용하지 않도록 보호
- 출격 직전 또는 레이드에서 출격품 소비 저장이 실패하면 레이드를 취소하고 아이템을 거점으로 반환해 저장 불일치와 복제 방지

창고, 출격 준비, 시설 레벨과 임무 진행도는 `Application.persistentDataPath/hideout_save.json`에 저장됩니다. 따라서 게임을 종료하고 다시 실행해도 마지막 거점 상태가 복원됩니다.

## 실행

1. Unity Hub에서 저장소 루트를 Unity 2022.3.62f2로 엽니다.
2. `Assets/_Game/Scenes/Bootstrap.unity`를 엽니다.
3. Play를 누릅니다.
4. 저장 데이터를 불러온 뒤 Hideout으로 자동 이동합니다. 바로 이동하려면 Bootstrap 화면의 `거점으로 들어가기` 버튼을 누릅니다.
5. Hideout에서 WASD로 이동합니다. 창고·임무 보드·제작대·치료소·발전기 가까이에서 E키를 누르면 해당 시설 화면이 열리고, Tab 또는 Esc로 닫을 수 있습니다.
6. 임무 보드에서는 현재 레벨에 공개된 임무를 골라 하나를 받습니다. 처치·회수·탈출 목표를 달성한 뒤 `보상 받기`를 누르면 실제 보상이 창고에 들어갑니다. 공간이 부족하면 임무는 그대로 남습니다.
7. 시설 화면의 오른쪽 강화 패널에서 현재 효과와 다음 비용을 확인합니다. 레이드에서 얻은 고철·전자 부품·천 조각이 충분하면 강화할 수 있습니다.
8. 제작대에서는 공개된 탄약 제작법을 이전·다음으로 고르고 제작합니다. 치료소에서는 천 조각과 고철로 구급상자를 만들며, 발전기 레벨이 높으면 필요한 재료가 줄어듭니다.
9. 창고에서 출격 준비를 마치고 아래 출격 버튼을 누릅니다.
10. WASD로 이동하고 마우스로 조준합니다. 청록색 조준 표시가 지면 위 커서 위치를 보여 주며, 이동 방향과 달라도 캐릭터는 마우스 방향을 우선해 바라봅니다.
11. 테스트 레이드는 보조무기 슬롯에 권총을 실제 장착한 상태로 시작합니다. WASD와 Shift를 함께 눌러 기력을 소비하며 달리고, 마우스 왼쪽 버튼으로 발사하고 R키로 재장전합니다. 1키는 주무기, 2키는 보조무기를 선택합니다. 소총과 기관단총은 버튼을 누르는 동안 자동 발사되고 장착 무기가 없으면 발사할 수 없습니다.
12. 권총·기관단총은 9mm, 소총은 5.56mm, 산탄총은 12게이지로만 재장전됩니다. 총기를 든 상태에서 마우스 오른쪽 버튼을 유지하면 카메라가 부드럽게 확대되고 총의 무작위 명중 오차가 줄어듭니다. 산탄총은 한 번 발사할 때 쉘 한 발만 줄지만 7개의 피해 판정을 부채꼴로 계산합니다.
13. 색상 Cube 아이템 가까이에서 E키를 누르면 바로 획득합니다. 작은 바닥 아이템은 충돌하지 않아 그대로 지나갈 수 있습니다.
14. Tab으로 인벤토리를 열고 아이템을 왼쪽 버튼으로 선택하거나 드래그합니다. 드래그 중에는 실제 배치 계산과 같은 기준으로 이동은 초록색, 중첩은 청록색, 교환은 노란색, 불가능한 위치는 빨간색으로 표시됩니다. 선택한 아이템은 R키로 회전하고, 장비 슬롯과 격자 사이에서도 드래그해 장착·해제·교환할 수 있습니다.
15. Ctrl+왼쪽 클릭은 현재 격자와 선택한 보조 격자 사이의 빠른 이동, Shift+왼쪽 클릭은 중첩 절반 분할입니다. 레이드 인벤토리에서 우클릭하면 아이템을 사용하거나 장착합니다. Delete는 한 번 눌러 경고를 확인한 뒤 제한 시간 안에 다시 눌러야 버리며, 테스트 지급품과 내용물이 든 컨테이너처럼 버릴 수 없는 항목은 이유를 표시합니다. 소형 구급상자는 1.5초 뒤 체력 35, 통조림은 1.2초 뒤 포만감 50을 회복합니다. 사용 중에는 진행률이 보이고 Tab으로 창을 닫으면 취소됩니다. 해당 수치가 가득 찼거나 1 미만만 비어 있다면 실패 이유를 표시하고 아이템을 소비하지 않습니다.
16. 남쪽 캠프에서 시작해 서쪽 주거 구역의 생활 보급품이나 동쪽 창고의 무기·탄약을 선택해 파밍하고 중앙 검문소를 지나 북쪽으로 이동합니다. 좀비를 처치하면 외곽 8개 지점 중 빈 생존 자리를 스폰 시스템이 다시 채웁니다. 50초 뒤부터 빠른 좀비, 120초 뒤부터 튼튼한 좀비가 출현 후보에 추가됩니다.
17. 초록색 생활 보급 상자, 회색 무기 상자와 갈색 은닉물 가까이에서 E키를 누르면 첫 수색 때 내용물이 생성됩니다. 무기 상자에서는 기관단총·산탄총과 관련 탄약도 나올 수 있습니다. 상자는 단단한 장애물이라 통과하거나 위로 올라갈 수 없습니다.
18. 좀비를 처치하면 전리품이 바닥에 즉시 나오지 않고 낮은 시체가 남습니다. 시체 가까이에서 E키를 누른 뒤 오른쪽 시체 격자에서 아이템을 직접 드래그합니다.
19. 파란색 무전기를 획득하고 좀비 3마리를 처치한 뒤 레이드 시작 25초가 지나면 탈출 조건이 완성됩니다. 북쪽 탈출 지점에 3초간 머물면 성공하며 구역을 벗어나면 카운트다운이 초기화됩니다.
20. 레이드에는 제한 시간과 시간 초과 실패가 없습니다. 플레이어가 사망하면 현재 소지품·장착 장비·가방과 조끼 내부 아이템을 모두 잃습니다. 결과와 손실 수량이 표시되는 동안 좀비 행동도 멈추며 2초 후 Hideout으로 이동합니다.
21. 탈출 성공 아이템은 왼쪽 12×10 창고 격자에 지급됩니다. 아이템을 오른쪽 출격 격자로 드래그하거나 Ctrl+왼쪽 클릭으로 빠르게 옮깁니다. 가방이나 조끼를 왼쪽 클릭하면 내부 격자가 열려 부모 격자와 내용물을 같은 방식으로 정리할 수 있습니다.
22. 거점에서도 Shift+왼쪽 클릭 분할, R키 회전과 각 격자의 자동 정리를 사용할 수 있습니다. 거점 우클릭 빠른 이동은 사용하지 않으며, 선택한 아이템의 상세 정보와 무기 비교를 확인한 뒤 아래 출격 버튼으로 RaidPrototype에 다시 진입합니다.
23. 출격품은 새 레이드의 플레이어 인벤토리에 자동 배치됩니다. 공간이 없거나 정의를 찾지 못한 항목은 창고로 되돌아갑니다.
24. 창고에서 아이템을 옮기거나 임무를 받은 뒤 Play를 종료했다가 다시 시작해도 창고, 출격 준비, 시설 레벨, 임무 진행도와 총기별 탄창 수량이 복원됩니다.

기본 테스트 콘텐츠 전체를 의도적으로 초기 상태로 되돌려야 할 때만 Unity 메뉴에서 `Tools > 2.5D Zombie Survival > Rebuild Prototype Content`를 실행합니다. 거점만 다시 만들 때는 `Rebuild Hideout Only`를 사용할 수 있습니다. 생성 도구는 평소 자동 실행되지 않으므로 직접 수정한 씬과 프리팹을 갑자기 덮어쓰지 않습니다. 일부만 누락됐을 때는 Rebuild보다 해당 프리팹이나 에셋을 Inspector에서 직접 복구하는 편이 안전합니다.

## UI 모양 바꾸기

`Assets/_Game/Prefabs/UI`에서 다음 프리팹을 열어 코드 수정 없이 화면 디자인을 바꿀 수 있습니다.

- `InventoryGridCell.prefab`: 비어 있는 격자 한 칸의 이미지와 색상
- `InventoryItemCell.prefab`: 아이템이 실제로 차지한 한 칸의 이미지
- `InventoryItem.prefab`: 아이템 이름·수량 글자, 선택/드래그 색상
- `EquipmentSlot.prefab`: 장비 슬롯의 배경 이미지와 글자
- `InventoryCanvas.prefab`: 전체 배치, 배경, 안내 문구와 크기
- `RaidHudCanvas.prefab`: 현재 구역, 무기·탄약·체력·포만감·기력, 탈출 안내, 피격 막과 레이드 결과 화면
- `BootstrapCanvas.prefab`: 저장 불러오기 상태와 거점 입장 버튼 화면
- `HideoutCanvas.prefab`: 직전 결과, 두 격자, 아이템 상세·조작 안내와 출격 버튼 화면
- `HideoutMissionCanvas.prefab`: 임무 선택·수락·포기, 목표와 누적 진행도 화면
- `HideoutFacilityUpgradeCanvas.prefab`: 시설 효과·강화 재료와 제작법 선택·제작 버튼 화면
- `HideoutWorldCanvas.prefab`: 거점 제목, 이동 방법과 가까운 시설의 E키 상호작용 안내

Image 컴포넌트의 `Source Image`에 원하는 Sprite를 넣으면 됩니다. 인벤토리의 열기·닫기 시간과 축소 비율은 `InventoryCanvas.prefab` 루트의 `InventoryHud > 열기/닫기 효과`에서 바꿀 수 있습니다. UI를 기본 모양으로 완전히 다시 만들고 싶을 때만 해당 UI 프리팹을 삭제한 뒤 Rebuild를 실행합니다.
