# LAST SALVAGE

**마지막 회수 작전** — Unity 2022.3.62f2와 URP로 만든 3D 월드 기반 2.5D 탑다운 좀비 익스트랙션 프로토타입입니다. `LAST SALVAGE`는 최종 상표 검토 전까지 사용하는 가제입니다.

## 코드 학습

전체 코드의 역할, 시스템 연결 관계와 초보자용 추천 학습 순서는 [`CODE_STUDY_GUIDE.md`](CODE_STUDY_GUIDE.md)에 정리되어 있습니다. 다른 채팅에서 코드를 천천히 설명받을 때 사용할 수 있는 복사용 시작 문장도 문서 마지막에 포함되어 있습니다.

## 현재 구현 범위

- `Title`, `Loading`, `Hideout`, 기능 검증과 실제 출격을 함께 담당하는 임시 학교 맵 `RaidSchool` 씬
- 별도 Title 씬의 `게임 시작 / 게임 로드 / 설정 / 종료` 메뉴와, 공용·해금 지역 이미지를 무작위로 보여 주며 목적지 씬을 비동기로 준비하는 Loading 씬
- 플레이어가 직접 걸어 다니며 E키로 창고·임무 보드·제작대·치료소·발전기·상인·출격 터미널을 사용하는 24×24 물리 거점
- 거점 어디서나 Tab으로 실제 창고·출격 인벤토리를 열고 같은 키 또는 Esc로 닫는 단축키
- 고철·전자 부품·천 조각을 소비하는 시설 강화, 레벨별 월드 외형 변화와 실제 기능 효과
- 창고 레벨별 보관 행 확장, 임무 보드 레벨별 공개 임무 증가, 발전기 레벨별 제작 비용 할인
- 제작대·치료소의 최대 3칸 제작 대기열, 시설 레벨별 시간 단축, 발전기 연료 소모·정지와 완성품 수령
- 크레딧을 사용하는 상인 구매·판매, 상인 평판·레벨별 상품 해금, 레이드마다 바뀌는 조건부 재고와 두 번 확인 거래
- 선행 임무, 위험도와 크레딧 보상을 가진 연속 임무 구조
- 좀비·특정 무기 처치, 아이템·구역 아이템 회수, 성공·무피해 탈출과 학교 구역 방문 임무, 일회성/반복 가능 규칙과 완료 기록
- 임무 완료 시 실제 아이템 보상을 창고에 지급하고, 전체 보상 공간이 부족하면 아무것도 바꾸지 않는 안전 검사
- 남쪽 시작 캠프→서쪽 주거·보급 구역/동쪽 창고·무기 구역→중앙 검문소→북쪽 탈출 구역으로 이어지는 3D 파밍 맵
- 충돌 가능한 외곽 벽·건물 잔해·창고 선반·검문소 엄폐물과 이동을 막지 않는 구역별 바닥 색상
- `CharacterController` 기반 WASD 이동(대각선 속도 정규화)
- 인벤토리를 열어도 계속되는 레이드 포만감 감소와 포만감 20 미만에서 최대 75%까지 적용되는 이동 속도 페널티
- 좌우 Shift 달리기, 100 기력의 소모·회복과 완전 고갈 뒤 25까지 회복해야 다시 달릴 수 있는 탈진 규칙
- Space 전방 구르기: 바라보는 방향으로 0.24초 동안 약 3m 이동하며 무적, 최대 기력의 25% 소비와 종료 후 0.55초 재사용 대기
- 마우스 위치를 지면에 투영하는 조준과 이동 중에도 커서 방향을 우선하는 8방향 캐릭터 주시
- 총기를 든 채 우클릭을 유지하면 FOV가 부드럽게 확대되고 명중 오차가 기본값의 35%로 감소하는 정밀 조준
- 카메라를 향하는 2D 플레이어 스프라이트와 3D 캡슐 충돌체
- 고정 각도 카메라 추적
- 마우스 좌클릭과 Raycast 기반 장착 무기 명중 판정
- 발사 위치부터 명중점까지 표시되는 짧은 탄도선과 총구 빛
- 외부 음원 없이 생성되는 임시 발사·피격·사망 효과음
- `WeaponDefinition` 기반 무기별 피해량, 사거리, 연사 속도, 재장전 시간, 탄창, 사용 탄종, 명중 오차와 적 밀림
- `MeleeWeaponDefinition` 기반 근접무기 공통 구조, 빠른 단일 대상 단검과 느리지만 최대 3명을 공격하는 도끼
- 반자동 10발 권총, 자동 20발 소총, 자동 30발 기관단총과 반자동 5발 산탄총
- 권총·기관단총은 9mm, 소총은 5.56mm, 산탄총은 12게이지만 사용하며 다른 탄종으로는 재장전할 수 없음
- 산탄총은 쉘 한 발을 소비해 7개 펠릿을 16도 범위로 발사하고 가까운 거리에서 최대 98 피해
- R키 재장전 시 인벤토리의 맞는 탄약 묶음을 실제로 소비하고, 부족하면 남은 양만큼만 장전
- 무기 인스턴스마다 탄창 수량을 따로 유지하고 레이드 결과와 거점 저장에도 남은 장탄 수 보존
- 테스트 레이드 시작 시 보조무기 슬롯에 실제 권총 장착, 무장 해제 상태에서는 발사 차단
- 테스트 지급 권총도 실패 시 제거하지만 무료 장비이므로 탈출 보상과 사망 손실 수량에서는 제외해 창고 복제 방지

- 출혈 중 화면 가장자리의 붉은 점멸 경고와 골절 중 이동·조준·재장전 불이익

- 조준경·총구·탄창 부착물과 무기별 호환 검사, 부착 상태 저장
- 방탄복 현재 내구도를 장비 슬롯·아이템 상세·체력 HUD에 표시하고 레이드 결과와 저장 파일에 보존

- 버전 10 JSON 파일로 격자·장비, 시설·임무, 상인 평판·재고, 제작 대기열·발전기 연료와 튜토리얼 진행을 게임 종료 후에도 보존
- 버전 1~9 저장 파일 호환, 평탄화된 부모 인덱스 구조, 손상 데이터 검증과 직전 정상 저장 `.bak` 자동 복구
- 보상 수령, 창고 이동, 출격 시작 시 자동 저장하고 손상된 저장 파일은 현재 메모리에 적용하지 않도록 보호
- 출격 직전 또는 레이드에서 출격품 소비 저장이 실패하면 레이드를 취소하고 아이템을 거점으로 반환해 저장 불일치와 복제 방지

창고, 출격 준비, 시설 레벨과 임무 진행도는 `Application.persistentDataPath/hideout_save.json`에 저장됩니다. 따라서 게임을 종료하고 다시 실행해도 마지막 거점 상태가 복원됩니다.

## 실행

1. Unity Hub에서 저장소 루트를 Unity 2022.3.62f2로 엽니다.
2. `Assets/_Game/Scenes/Title.unity`를 엽니다.
3. Play를 누릅니다.
4. `LAST SALVAGE` 타이틀에서 새 기록은 `게임 시작`, 기존 기록은 `게임 로드`를 누릅니다. 저장이 없으면 로드 버튼이 비활성화되고, 기존 저장이 있는 상태에서 새 게임을 누르면 삭제 확인창이 표시됩니다. 선택 뒤 Loading 화면이 해금된 이미지 중 한 장을 전체 화면으로 보여 주고 실제 비동기 진행률을 표시한 다음 Hideout으로 이동합니다.
5. Hideout에서 WASD로 이동합니다. 창고·임무 보드·제작대·치료소·발전기·상인·출격 터미널 가까이에서 E키를 누르면 해당 시설 화면이 열리고, Tab 또는 Esc로 닫을 수 있습니다. 시설이 열려 있지 않을 때 Tab을 누르면 어디서든 창고·출격 인벤토리를 엽니다.
6. 임무 보드에서는 현재 레벨에 공개된 임무를 골라 하나를 받습니다. 처치·회수·탈출·학교 구역 방문 목표를 달성한 뒤 `보상 받기`를 누르면 실제 보상이 창고에 들어갑니다. 공간이 부족하면 임무는 그대로 남습니다.
7. 시설 화면의 오른쪽 강화 패널에서 현재 효과와 다음 비용을 확인합니다. 레이드에서 얻은 고철·전자 부품·천 조각이 충분하면 강화할 수 있습니다.
8. 제작대·치료소에서 제작을 시작하면 재료가 투입되고 시간이 흐른 뒤 같은 버튼으로 완성품을 수령합니다. 최대 3개를 대기열에 둘 수 있고 발전기가 꺼지거나 연료가 없으면 시간이 멈춥니다.
9. 창고 또는 Tab 인벤토리에서 출격 준비를 마친 뒤 남쪽 출격 터미널을 사용합니다. 무기·탄약·치료품·가방 점검 경고를 확인하고 출격 버튼을 한 번 더 눌러 학교로 이동합니다.
10. WASD로 이동하고 마우스로 조준합니다. 청록색 조준 표시가 지면 위 커서 위치를 보여 주며, 이동 방향과 달라도 캐릭터는 마우스 방향을 우선해 바라봅니다.
11. 테스트 레이드는 보조무기 슬롯에 권총을 실제 장착한 상태로 시작합니다. WASD와 Shift를 함께 눌러 기력을 소비하며 달리고, 마우스 왼쪽 버튼으로 공격하고 R키로 총기를 재장전합니다. 1키는 주무기, 2키는 보조무기를 선택합니다. 단검·도끼는 탄약 없이 근접 공격하고, 아무 무기도 없으면 맨손 공격을 사용합니다.
12. 권총·기관단총은 9mm, 소총은 5.56mm, 산탄총은 12게이지로만 재장전됩니다. 총기를 든 상태에서 마우스 오른쪽 버튼을 유지하면 카메라가 부드럽게 확대되고 총의 무작위 명중 오차가 줄어듭니다. 산탄총은 한 번 발사할 때 쉘 한 발만 줄지만 7개의 피해 판정을 부채꼴로 계산합니다.
13. 색상 Cube 아이템 가까이에서 E키를 누르면 바로 획득합니다. 작은 바닥 아이템은 충돌하지 않아 그대로 지나갈 수 있습니다.
14. Tab으로 인벤토리를 열고 아이템을 왼쪽 버튼으로 선택하거나 드래그합니다. 아이템이나 장비 슬롯을 0.45초간 움직이지 않고 누르면 설명 길이에 맞는 정보 팝업이 커서 옆에 나타납니다. 손을 떼도 팝업은 유지되며 상단 제목 바를 드래그해 옮기고, X 버튼이나 팝업 바깥을 클릭해 닫을 수 있습니다. 드래그 중에는 실제 배치 계산과 같은 기준으로 이동은 초록색, 중첩은 청록색, 교환은 노란색, 불가능한 위치는 빨간색으로 표시됩니다. 선택한 아이템은 R키로 회전하고, 장비 슬롯과 격자 사이에서도 드래그해 장착·해제·교환할 수 있습니다.
15. Ctrl+왼쪽 클릭은 현재 격자와 선택한 보조 격자 사이의 빠른 이동, Shift+왼쪽 클릭은 중첩 절반 분할입니다. 레이드 인벤토리에서 우클릭하면 아이템을 사용하거나 장착합니다. Delete는 한 번 눌러 경고를 확인한 뒤 제한 시간 안에 다시 눌러야 버리며, 테스트 지급품과 내용물이 든 컨테이너처럼 버릴 수 없는 항목은 이유를 표시합니다. 붕대는 출혈, 부목은 골절, 소형 구급상자는 전체 체력만 치료합니다. 출혈은 초당 체력을 줄이면서 화면 가장자리에 붉은 테두리를 표시하며 피격 점멸·흔들림·피격음을 반복하지 않습니다. 골절은 이동·조준·재장전에 불이익을 줍니다. 치료 도중 직접 공격을 받거나 Tab으로 창을 닫으면 취소되며 아이템은 소비되지 않습니다. 출혈 피해는 치료를 취소하지 않으며 효과가 실제 적용된 완료 순간에만 한 개를 소비합니다.
16. 84×84 학교 정문에서 시작해 주차장과 행정동·보건실, 2층 일반 교실동, 중앙정원, 특별실·도서관동, 급식실·조리실과 체육관을 수색한 뒤 운동장 비상문으로 이동합니다. 투과된 천장 너머에는 현재 플레이어와 같은 층의 아이템·상자·시체·좀비만 표시됩니다. 좀비를 처치하면 외곽과 실내의 17개 지점 중 플레이어와 멀고 비어 있는 위치를 스폰 시스템이 다시 채웁니다. 위험도 3부터 비명형, 위험도 4부터 튼튼한 좀비가 해당 구역 후보가 되며 각 종류의 시간 해금 조건도 함께 적용됩니다.
17. 초록색 생활 보급 상자, 회색 무기 상자와 갈색 은닉물 가까이에서 E키를 누르면 첫 수색 때 내용물이 생성됩니다. 무기 상자에서는 기관단총·산탄총·단검·도끼와 관련 탄약도 나올 수 있습니다. 상자는 단단한 장애물이라 통과하거나 위로 올라갈 수 없습니다.
18. 좀비를 처치하면 전리품이 바닥에 즉시 나오지 않고 낮은 시체가 남습니다. 시체 가까이에서 E키를 누른 뒤 오른쪽 시체 격자에서 아이템을 직접 드래그합니다.
19. 파란색 무전기를 획득하고 좀비 3마리를 처치한 뒤 레이드 시작 25초가 지나면 탈출 조건이 완성됩니다. 북쪽 탈출 지점에 3초간 머물면 성공하며 구역을 벗어나면 카운트다운이 초기화됩니다.
20. 레이드에는 제한 시간과 시간 초과 실패가 없습니다. 플레이어가 사망하면 과다 출혈 또는 마지막 공격 종류와 명중 위치가 결과에 표시되고 현재 소지품·장착 장비·가방과 조끼 내부 아이템을 모두 잃습니다. 결과와 손실 수량이 표시되는 동안 좀비 행동도 멈추며 2초 후 Hideout으로 이동합니다.
21. 탈출 성공 아이템은 왼쪽 12×10 창고 격자에 지급됩니다. 아이템을 오른쪽 출격 격자로 드래그하거나 Ctrl+왼쪽 클릭으로 빠르게 옮깁니다. 가방이나 조끼를 왼쪽 클릭하면 내부 격자가 열려 부모 격자와 내용물을 같은 방식으로 정리할 수 있습니다.
22. 거점에서도 Shift+왼쪽 클릭 분할, R키 회전과 각 격자의 자동 정리를 사용할 수 있습니다. 거점 우클릭 빠른 이동은 사용하지 않으며, 아이템을 길게 눌러 상세 정보와 무기 비교 팝업을 확인한 뒤 별도 출격 터미널에서 학교 지역으로 출발합니다.
23. 출격품은 새 레이드의 플레이어 인벤토리에 자동 배치됩니다. 공간이 없거나 정의를 찾지 못한 항목은 창고로 되돌아갑니다.
24. 창고 변경·임무·상인·제작 상태는 자동 저장되고 이전 정상 파일은 `.bak`으로 남습니다. ESC 설정에서 글자 크기·피격 효과·화면 흔들림을 조절하고 튜토리얼을 다시 시작하거나, 확인 후 새 게임으로 전체 진행을 초기화할 수 있습니다.

기본 테스트 콘텐츠 전체를 의도적으로 초기 상태로 되돌려야 할 때만 Unity 메뉴에서 `Tools > 2.5D Zombie Survival > Rebuild Prototype Content`를 실행합니다. 거점만 다시 만들 때는 `Rebuild Hideout Only`, 학교 동선만 다시 만들 때는 `Rebuild School Raid Only`를 사용할 수 있습니다. 아이템 팝업 구조만 기존 프리팹에 보충할 때는 `Upgrade Item Detail Popups Only`, Title과 Loading만 복구할 때는 `Rebuild Title and Loading Scenes Only`를 사용합니다. 이번 학교·임무·UI 업그레이드는 새 코드가 처음 임포트될 때 한 번만 자동 적용되며, 다시 적용해야 하면 `Apply Playable Prototype Upgrade`를 사용합니다. 이후 일반적인 Unity 실행에서는 씬을 자동 재생성하지 않습니다.

## UI 모양 바꾸기

`Assets/_Game/Prefabs/UI`에서 다음 프리팹을 열어 코드 수정 없이 화면 디자인을 바꿀 수 있습니다.

- `InventoryGridCell.prefab`: 비어 있는 격자 한 칸의 이미지와 색상
- `InventoryItemCell.prefab`: 아이템이 실제로 차지한 한 칸의 이미지
- `InventoryItem.prefab`: 아이템 이름·수량 글자, 선택/드래그 색상
- `EquipmentSlot.prefab`: 장비 슬롯의 배경 이미지와 글자
- `InventoryCanvas.prefab`: 전체 배치, 배경, 안내 문구와 크기
- `RaidHudCanvas.prefab`: 현재 구역, 무기·탄약·체력·포만감·기력, 탈출 안내, 피격 막과 레이드 결과 화면
- `TitleCanvas.prefab`: 제목·부제·태그라인, `게임 시작 / 게임 로드 / 설정 / 종료`, 설정 패널과 확인창이 분리된 타이틀 화면. 각 Text와 Image는 Inspector에서 직접 교체 가능
- `LoadingCanvas.prefab`: 무작위 전체 화면 원화, 상태·백분율과 화면 아래에서 띄운 실제 진행 막대를 표시하는 공용 로딩 화면
- `loading_screen_catalog.asset`: 항상 사용할 공용 이미지와 출격 가능 지역별 해금 이미지를 연결하는 로딩 카탈로그
- `HideoutCanvas.prefab`: 직전 결과, 창고·출격 인벤토리 두 격자와 길게 누르기 아이템 정보 팝업·조작 안내 화면
- `HideoutDeploymentCanvas.prefab`: 레이드 지역 설명·위험도·출격 준비 수량과 실제 출격 버튼 화면
- `HideoutMissionCanvas.prefab`: 임무 선택·수락·포기, 목표와 누적 진행도 화면
- `HideoutFacilityUpgradeCanvas.prefab`: 시설 효과·강화 재료와 제작법 선택·제작 버튼 화면
- `HideoutTraderCanvas.prefab`: 크레딧, 상품 구매와 창고 아이템 판매 화면
- `HideoutWorldCanvas.prefab`: 거점 제목, 이동 방법과 가까운 시설의 E키 상호작용 안내

아이템 팝업은 각 Canvas 프리팹의 `DragLayer > ItemDetailPanel` 아래에 `Header`, `Header > Title`, `Header > CloseButton`, `ItemDetailText`가 나뉘어 있습니다. 배경·제목 바·닫기 버튼·본문을 Inspector에서 각각 수정할 수 있고, 전체 화면 바깥 클릭 영역은 `DragLayer > ItemDetailDismissArea`입니다. Image 컴포넌트의 `Source Image`에 원하는 Sprite를 넣으면 됩니다. 인벤토리의 열기·닫기 시간과 축소 비율은 `InventoryCanvas.prefab` 루트의 `InventoryHud > 열기/닫기 효과`에서 바꿀 수 있습니다. UI를 기본 모양으로 완전히 다시 만들고 싶을 때만 해당 UI 프리팹을 삭제한 뒤 Rebuild를 실행합니다.
